プライバシーポリシー

sleep-sync（以下「本ツール」）における個人データの取り扱いについて。

本ツールの性質

本ツールは、作者（GitHub: harutomiyai）が自分自身の記録のために作った個人用のスクリプトです。 一般に配布しておらず、作者以外の利用者はいません。サーバーを持たず、 作者のパソコン上でのみ動作します。

取得する情報

Google アカウントの認可を受けて、Google Health API から 作者本人の睡眠データを読み取ります。使用する権限は次のひとつだけです。

  • https://www.googleapis.com/auth/googlehealth.sleep.readonly（読み取り専用）

読み取る内容は次のとおりです。

  • 睡眠セッションの開始時刻と終了時刻
  • 睡眠ステージ（浅い・深い・レム・覚醒）の区間
  • 短い目覚めの記録

これ以外のデータ（位置情報、連絡先、メール、健康指標その他）は取得しません。 Google 上のデータへの書き込みや削除も行いません。

情報の保存場所

読み取ったデータは、作者本人のパソコンの中にある個人的なノート（非公開の保管庫）に 書き出されます。認証情報（アクセストークンおよびリフレッシュトークン）は、 同じパソコンのホームディレクトリ内に、本人のみが読める権限で保存されます。

第三者提供

取得したデータを第三者へ提供・販売・共有することはありません。 広告、プロファイリング、機械学習モデルの学習には使用しません。 データが外部のサーバーへ送信されることはありません。

利用目的

作者が自分の生活と体調を記録し、振り返るためだけに使用します。 それ以外の目的には使用しません。

アクセスの取り消し

Google アカウントの アカウントにアクセスできるアプリ から、本ツールへの許可をいつでも取り消せます。取り消すと、それ以降データは読み取られません。

Google ユーザーデータの取り扱い

本ツールによる Google API から取得した情報の使用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に準拠します。
